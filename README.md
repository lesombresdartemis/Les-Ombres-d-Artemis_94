# Les Ombres d’Artémis — Site V5.33

Version GitHub Pages basée sur la **V5.31**.

## Mise à jour V5.33

- **Les Enfants de Bifröst** sont placés immédiatement après **Hestia** dans la liste des protégés, afin de conserver la continuité de lecture ;
- couvertures actualisées avec les photos validées pour **Freyja, Baldr, Máni et Mégara** ;
- les fiches restent sur la **mise en page validée du site**, sans nouveau modèle ;
- suppression des mentions de suivi vétérinaire détaillé dans les fiches (poids, vaccination, vermifuge/antiparasitaires) ;
- la mention **stérilisé / stérilisée** est conservée lorsqu’elle est pertinente ;
- le lien **Parrainage** est présent sur chaque fiche ;
- formulaire de contact, réseaux sociaux, QR code, HelloAsso et autres contenus de la V5.31 conservés.

## Mise en ligne

Le point d’entrée est `index.html`. Décompresser le ZIP et envoyer tous les fichiers à la racine du dépôt GitHub Pages.
